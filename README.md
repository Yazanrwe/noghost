# NoGhost

مود فابرك **Minecraft 1.20.1** (كلاينت فقط، ما يحتاج Fabric API) يقلل القوستات (ghost blocks) ويقصّر وقت تصحيحها.

Client-side Fabric mod for 1.20.1 that detects and heals ghost blocks quickly.

## وش يسوي

**1. علاج القوستات (مفعّل افتراضيًا)**
كل بلوك تكسره أو تحطه، الكلاينت يتوقعه عنده فورًا. السيرفر الطبيعي دايم يرد بتحديث للبلوك (سواء قبل الحركة أو رفضها). إذا ما جاك أي رد خلال حوالي بنق + تك، معناها السيرفر تجاهل الحركة (بلقن، أنتي تشيت، ViaVersion، فقد باكيت) وممكن يبقى عندك بلوك وهمي. وقتها المود يطلب من السيرفر الحالة الحقيقية لهذا البلوك بس (باكيت `ABORT_DESTROY_BLOCK`)، وما يرسلها وأنت تكسّر بلوك.

- وقت الانتظار يعتمد على البنق الحالي تلقائيًا.
- لو السيرفر رجّعك للخلف (rubberband) يطلب تصحيح كل البلوكات غير المؤكدة فورًا.
- ما يرسل شي إذا السيرفر يرد طبيعي، فما فيه ضغط إضافي على الشبكة.

**2. تقليل الديلاي (مطفّى افتراضيًا)**
تقدر تقصّر الانتظار الأساسي في ماينكرافت بين كسر بلوكين (5 تك) وبين وضع بلوكين (4 تك). هذا يشبه fast place / fast break وكثير من السيرفرات تعتبره غش وتبندك، عشان كذا مطفّى لين تفعّله بنفسك.

## الإعدادات

الملف `config/noghost.json` يتولد أول تشغيل (يتطلب إعادة تشغيل اللعبة بعد التعديل):

| الخيار | الافتراضي | الوصف |
|---|---|---|
| `autoResync` | `true` | يطلب الحالة الحقيقية للبلوكات غير المؤكدة |
| `resyncExtraTicks` | `1` | تكات إضافية فوق (بنق + تك سيرفر) قبل الطلب |
| `minResyncDelayTicks` | `2` | أقل وقت انتظار |
| `maxResyncDelayTicks` | `20` | أقصى وقت انتظار |
| `maxResyncsPerTick` | `6` | حد أقصى للباكيتات في التك |
| `resyncOnRubberband` | `true` | تصحيح فوري لما السيرفر يرجّعك |
| `reduceCooldowns` | `false` | تفعيل تقليل الكولداون (خطر باند) |
| `breakCooldownTicks` | `0` | الانتظار بين كسر بلوكين (الأصلي 5) |
| `placeCooldownTicks` | `0` | الانتظار بين وضع بلوكين (الأصلي 4) |

لو تبي أقصى سرعة: خلّ `reduceCooldowns` = `true`.

## الحصول على الـ jar

- من تبويب **Releases** في الريبو: النسخة `latest` تتبنى تلقائيًا مع كل push على `main`.
- أو من **Actions** ← آخر build ← artifact `noghost-jar`.
- أو محليًا (يحتاج JDK 17): `./gradlew build` والملف يطلع في `build/libs/noghost-1.0.0.jar`.

ضعه في مجلد `mods` مع Fabric Loader 0.14.21 أو أحدث.

## حدود المود

- ما يقلل البنق الحقيقي ولا لاق السيرفر؛ بس يقلل المدة اللي تبقى فيها القوستات.
- ما يقدر يصلح قوستات سببها السيرفر نفسه يرسل حالة غلط.
- ممكن بعض الأنتي تشيت تستغرب باكيت `ABORT_DESTROY_BLOCK` بدون كسر؛ لو صار معك شي، طفّ `autoResync`.
